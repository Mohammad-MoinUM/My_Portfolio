# My Portfolio

A modern, responsive, and secure personal portfolio website built with **PHP**, **MySQL**, **HTML**, **CSS**, and **JavaScript**.  
This portfolio allows to showcase my **projects**, **skills**, **education**, and **experience** with an integrated **admin panel** for easy content management.

---
